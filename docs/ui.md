# Bili CC 界面规范

Bili CC 的主任务是提取字幕、快速复制和继续阅读。Web、Android 和扩展共用薰衣草紫品牌色与同一款图标。Web、Android 的页面分组参考 ColorOS，把输入、字幕、登录和设置分别做成清晰可扫读的区域。 [OPPO ColorOS 设计说明](https://www.oppo.com/en/newsroom/press/oppo-color-os-17/)

## 颜色

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 页面底色 | `#F6F4FA` | `#201925` | 页面与 Android 系统栏底色 |
| 卡片 | `#FFFFFF` | `#2B2233` | 表单、结果、设置、登录 |
| 输入与预览底色 | `#F9F7FC` | `#19141E` | 控件和大段字幕 |
| 正文 | `#231B2C` | `#F5EDF8` | 标题与字幕 |
| 次要文字 | `#62576D` | `#C4B5CC` | 输入提示、视频分 P、说明 |
| 分隔线 | `#E6DEED` | `#44364F` | 卡片和预览区轮廓 |
| 控件描边 | `#8B7C99` | `#8C7C99` | 输入框和选择框 |
| 主要操作 / 文字 | `#55378F` / `#FFFFFF` | `#DCD0FF` / `#251739` | 提取、保存 |
| 次级操作 / 文字 | `#EBE2FA` / `#452776` | `#403055` / `#EEDFFF` | 复制、测试连接 |
| 成功 / 错误 | `#246447` / `#9D2846` | `#ACDABB` / `#FFB5C6` | 状态文案，配合实际文字 |

Web 主题定义在 [style.css](../web/style.css)，Android 定义在 [浅色资源](../android/app/src/main/res/values/colors.xml)和[深色资源](../android/app/src/main/res/values-night/colors.xml)。两端跟随系统主题。调整颜色时同步检查两端的正文、次要文本、按钮文字和控件描边。正文目标对比度至少 4.5:1，控件描边至少 3:1。 [WCAG 2.2](https://www.w3.org/TR/WCAG22/)

## 排版与尺寸

| 项目 | Web | Android |
| --- | --- | --- |
| 页标题 | 30–48，随视口调整 | 30sp |
| 卡片标题 | 18px | 19sp |
| 正文与字幕 | 16px，字幕行高 1.8 | 16sp，字幕另加 4dp 行距 |
| 表单标签与操作 | 14px | 14sp |
| 页面间距 | 16px 起，卡片内 16–24px | 两侧 18dp，卡片内 16dp |
| 圆角 | 卡片 24px，控件 14px | 卡片 24dp，控件 14dp |
| 可点击区域 | 操作和选择控件至少 48px 高 | 至少 48dp × 48dp |

默认使用系统字体与中文回退，字号跟随浏览器或 Android 字体设置。Web 保留可见键盘焦点。Android 保留原生控件、无障碍标签，以及系统栏、刘海和输入法的安全区。 [Android Views 无障碍指南](https://developer.android.com/guide/topics/ui/accessibility/views/apps-views)

## 布局与交互

- **Web** 在 760px 以上左侧放视频链接和提取操作，右侧放字幕预览。窄屏改为单列。字幕可滚动、选择和调整阅读区域高度。登录在当前页的原生对话框中完成，保留二维码保存和登录链接。
- **Android** 顶栏放登录与连接设置。首页依次显示输入、提取、字幕信息和预览。复制与 SRT 放在长字幕前方。设置按主用／备用连接和分享模式分组，每条连接的测试结果显示在对应卡片里。
- **动作层级** 用主按钮提交当前任务，用次级按钮放结果操作。退出、返回和下载等低频动作使用文字按钮。输入用可见标签，示例放在占位文字里。无结果时禁用复制与下载。
- **状态反馈** 有提取中、成功、无字幕和错误。通过文字说明结果，颜色辅助区分。Android 分享入口沿用系统 Toast。二维码保留白底，避免深色模式影响扫描。
- **动效** Web 按钮反馈 140ms，登录面板进入 260ms，跟随系统「减少动态效果」。Android 交互用原生按压反馈和系统过渡。
